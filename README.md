# Mangayomi Extensions (xFr0z3n)

Extensions for the Mangayomi app, maintained in this fork:

| Extension | Type | Site |
|---|---|---|
| Comix | Manga | comix.to |
| NovelFire | Novel | novelfire.net |

## Comix: human check

comix.to sometimes asks for a one-time "Verify you're human" check before it
shows chapters. If a title shows no chapters, tap the globe (WebView) button on
it, complete the check, then pull to refresh.
